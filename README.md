# Учебный проект социальной сети

## Как запустить

### База данных PostgreSQL
База данных запускается через docker-compose в папке data-base 
Логин и пароль пользователя приложени указываются в .env файле
 - команда: docker-compose up -d

### Приложение web api node js
Запускается командами:
 - npm run build
 - npm run start

Все секреты хранятся в .env файле
